## Установщик (MSI)

Готовый Windows-установщик приложения CheckMail:

- **Размещение:** `Installer\bin\CheckMail-1.0.0.msi`
- **Размер:** ~0,31 МБ (327 680 байт)
- **Версия:** 1.0.0

Установщик собран с помощью WiX Toolset v5. Исходники и скрипт сборки находятся
в каталоге [Installer](Installer/README.md).
